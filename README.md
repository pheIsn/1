# AURELIA — The Aurelia Observatory

A redesigned, Russian-language interactive 3D landing page for a fictional rocky planet. The visual direction is an atmospheric field observatory: deep mineral greens, warm copper details, editorial typography, a responsive chapter journey and an interactive Three.js planet.

## Run locally
Open `index.html` in a modern browser with WebGL support. The 3D engine is bundled locally; the CSS uses Google Fonts when online and falls back to system fonts when offline.

## Publish with GitHub Pages
Upload the files to the repository root and enable **Settings → Pages → Deploy from a branch → main → /(root)**. Keep `index.html`, `style.css`, `app.js`, and `three.local.js` together.

## Included
- Rebuilt visual identity and responsive layout
- Cinematic intro and scroll-linked chapter navigation
- Interactive planet, rings, moons, lighting and core cutaway
- Reduced-motion support and mobile layout
- Local Three.js build

The planet and its structure are fictional visual design, not a scientific simulation. `three.local.js` includes the Three.js library; retain its license notice and comply with the Three.js MIT license.

# AURELIA

Полноэкранная 3D-планета, которая живёт вместе со скроллом. Чистый HTML/CSS/JS + Three.js (локально, MIT), без сборки и без текстур.

## Запуск
Открой `index.html` в браузере с WebGL. Для GitHub Pages положи все 4 файла в корень репозитория: `index.html`, `style.css`, `app.js`, `three.local.js`.

## Как устроено
- Планета на весь экран за текстом. Заголовок AURELIA стоит *за* планетой, кольца проходят *перед* ним.
- Рельеф, кратеры, цвет и свет считаются шейдером на видеокарте (без картинок): поверхность не размывается вблизи.
- Тени: кольца на планету и планета на кольца; серп и дымка атмосферы; терминатор.
- Разрез ядра: убранный октант + грани со слоями кора / мантия / ядро.
- Скролл управляет позицией, масштабом, поворотом, наклоном колец, разрезом, направлением света и спутниками. Скорость скролла добавляет вращение.
- В последней главе: перетаскивание планеты, кольца, разрез, тёплый/холодный свет.
- `prefers-reduced-motion`, облегчённый режим для слабых устройств, авто-снижение разрешения при низком FPS.

Планета, её строение и орбиты — вымысел, не научная модель.
